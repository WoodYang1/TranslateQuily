# 项目名称
 TranslateQuily — 一个基于 Qt 的桌面翻译工具


## 功能特点
剪贴板翻译：连续复制两次自动翻译

手动输入翻译

系统托盘图标，支持状态切换

全局快捷键（F1 切换状态 / F2 打开输入窗口）

设置界面（API Key、AppId、默认语言、快捷键修改）

API Key、AppId通过小牛翻译获取

## 运行环境

Qt 6.8.3 或更高版本

C++17 或更高版本

操作系统：Windows 10 / 11

## 编译运行
1. 克隆仓库
bash
git clone https://github.com/WoodYang1/TranslateQuily.git
cd TranslateQuily
2. 用 Qt Creator 打开项目
打开 TranslateQuily.pro 文件，配置 Qt 版本和编译器（建议MinGW）。

3. 构建并运行
选择 Release 模式

点击 构建 → 构建项目“TranslateQuily”
